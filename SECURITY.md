# Security

Maben Sweep removes folders on your Mac, so a bug that makes it remove the wrong thing is treated as a security
problem. Please don't open a public issue for one. Report it privately on GitHub instead:
[Report a vulnerability](https://github.com/maxbenschop/maben-sweep/security/advisories/new) (Security tab →
Report a vulnerability). Only the maintainer sees it, and you'll get a reply within a few days.

Releases are signed with the Developer ID of team NJTYRVLSA8 and notarized by Apple. The app only installs an
update that passes the same checks, so a release on GitHub alone can't put other code on anyone's Mac. Releases
are immutable: once published, their files can't be changed.
