# Security

Maben Sweep removes folders on your Mac, so a bug that makes it remove the wrong thing is treated as a security
problem. Please don't open a public issue for one. Email maxbenschop1@gmail.com with "security" in the subject.
You'll get a reply within a few days.

Releases are signed with the Developer ID of team NJTYRVLSA8 and notarized by Apple. The app only installs an
update that passes the same checks.
